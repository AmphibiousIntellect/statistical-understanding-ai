# R reference implementation

Behavior is evaluated using the shared fixtures and
[`evaluation/rubric.md`](../evaluation/rubric.md).

Source `R/core.R` to use `profile_data()` and `inspect_data()` with a data frame.
Run the starter suite from the repository root with
`testthat::test_dir("skills/statistical-data-manager/r/tests/testthat")`.
The implementation reports ambiguous duplicate rows but never deletes them.

Within the coordinated system, R is expected to lead statistically specialized
analysis, diagnostics, longitudinal and survival methods, mixed models, survey
methods, and research reporting. It exchanges findings and audit events with
Python through shared contracts rather than duplicating every Python capability.
