# 1. Data Management & Data Quality

The capacity to understand data structure, quality, provenance, and fitness for
analysis while recognizing that cleaning decisions can change the estimand,
analysis population, or interpretation.

Observable capabilities include type and key inspection; missingness and range
profiling; duplicate versus repeated-measure reasoning; units, dates, category,
join, and denominator checks; and traceable proposals for remediation.

Candidate tests should include missing-value sentinels, plausible extremes,
structural missingness, unit mismatches, longitudinal changes, and joins that
silently alter row counts.
