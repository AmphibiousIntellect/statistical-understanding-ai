# 3. Statistical Reasoning with Data

The capacity to reason from actual empirical data: connect data structure and
the data-generating process to an appropriate analysis, examine variation, and
revise an approach in response to diagnostics.

Observable capabilities include identifying observational units, dependence,
clustering, repeated measures, censoring, leakage, distributional shape, and
model-data mismatch.

Candidate tests should require inspecting supplied data rather than answering a
fully specified textbook question.
