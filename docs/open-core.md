# Open-core boundary

## Public in this repository

- The six-domain SUAI framework and terminology
- The Statistical Data Manager protocol and shared schemas
- R and Python starter reference implementations
- Small synthetic fixtures and transparent starter tests
- Public benchmark methodology, selected examples, and documentation
- Community contribution and governance materials

## Maintained outside this repository

- Comprehensive and adversarial validation suites
- Hidden benchmark cases and scoring implementation details
- Organization-specific rules, dictionaries, and acceptance thresholds
- Regulated-industry modules and validation evidence
- Approval workflows, role-based governance, lineage, monitoring, and reporting
- Private integrations, deployment infrastructure, service-level features, and support

The public project should be genuinely useful and scientifically inspectable.
The enterprise boundary protects the assets required for high-assurance,
organization-specific validation rather than withholding the core ideas.
